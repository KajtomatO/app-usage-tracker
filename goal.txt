An android APP / widget.
Will track usage of APPs.
Apps can be grouped, then additionaly app wil track usage of entire group.
This application's goal is to encurage using those apps [languagne learning, reading] not to reduce it.
An individual widget will show usage [time] of a single group or an app.
For each group or an app user can specify up to three daily goals. [bronze, silver, gold] that when reached will show medals in app and widget and color tint should discretly reflect it as well.
The app should show usage of tracked apps / groups for today, last week, last month, year.
App can use system mechanism for tracking this time.
Widget tap should open app on relevant entry.
If possible, add refresh button or zone to widget
An "app-usage-tracker" is temp name. Recomend some alternatives.
